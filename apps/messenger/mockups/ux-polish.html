Implementation notes

Use the reference frame as the base component across all pages. Page content should change inside the parchment and rail regions, not create new flat panels.

Keep scroll containers fixed-height, place text on quieter parchment panels, and reserve generated/tablet assets for attachments or archive items outside the primary chat flow.

Replace generic icon buttons with asset-backed controls where assets exist; where icons remain, center them inside the stone asset rather than layering them beside it.
