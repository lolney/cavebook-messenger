# Cavebook imagegen mockups

These mockups were generated with the built-in `image_gen` tool using the original Cavebook Messenger reference image as the visual source. They are raster target comps, not HTML mockups.

## Outputs

- `cavebook-chat-target.png`: main Messenger page target.
- `cavebook-profile-target.png`: profile page target.
- `cavebook-artifacts-target.png`: artifacts/archive page target.

## Prompt notes

Common direction:

- Preserve the reference image's carved bone title plaques, lashed wooden frame, parchment chat surface, stone side rail, ochre cave drawings, tactile shadows, and handmade skeuomorphic controls.
- Improve usability: high-contrast readable text, centered asset-backed icons, fewer accidental overlaps, no emoji, no flat modern cards, no white attachment borders.
- Treat these as visual targets for app implementation, not source UI.

The compact/mobile target was attempted but the built-in generation path failed server-side twice, so it is not included.
